# 安沐心平台

平台方自用的管理后台：商户、密钥、任务、积分与运行参数的统一管理入口。
Vue 3 + Element Plus + Pinia + ECharts，构建工具为 Vite。

## 启动

```bash
npm install
npm run dev      # http://localhost:5180
npm run build    # 产物在 dist/
```

开发态通过 Vite 代理把 `/admin/api` 转发到 `http://127.0.0.1:8080`（Go 后端），
改地址请编辑 `vite.config.js`。生产部署时把 `dist/` 交给 Nginx，
并把 `/admin/api` 反代到后端即可。

首次使用需要先在后端创建管理员账号：

```bash
cd ../backend
go run ./cmd/server -create-admin admin -admin-password 你的密码
```

## 页面

| 路由 | 页面 | 能做什么 |
| --- | --- | --- |
| `/dashboard` | 数据概览 | 8 张指标卡；任务趋势（近 7/14/30 天）、任务类型分布、积分消耗趋势三张图 |
| `/merchants` | 商户管理 | 搜索、新建（可同时签发密钥）、重命名、启用/禁用、充值与手动调整积分 |
| `/keys` | 密钥管理 | 按商户筛选、生成新密钥（明文只展示一次）、启用/禁用、删除 |
| `/tasks` | 任务管理 | 按商户/类型/状态/时间/关键词筛选；详情抽屉含请求参数、上游返回、音视频试听；失败任务人工退款 |
| `/points` | 积分流水 | 按商户/类型/时间筛选，本页收支小计；直接发起充值或调整 |
| `/settings` | 系统设置 | 展示后端生效的 Provider、轮询、超时、限流等参数与 12 个接口的定价 |

## 登录与鉴权

- 登录后拿到 HMAC 签名令牌，存在 `localStorage`，默认 12 小时有效。
- axios 拦截器统一附加 `Authorization`，遇 401 自动清除令牌并跳回登录页。
- 后端口令用 PBKDF2-HMAC-SHA256（12 万次迭代）存储，只存哈希。

## 图表说明

配色取自经校验的分类色板（蓝 `#2a78d6` / 青 `#1baf7a` / 橙 `#eb6834`）：
相邻色对的色觉障碍可分辨度与常视辨识度均达标。青色在白底上对比度略低，
因此折线都带末端直标，识别不只依赖颜色。

任务类型分布用横向条形图而非饼图——12 个类目的排名比较，长度比角度更易读，
也便于直接标注数值。任务量与积分消耗量纲不同，拆成两张图而非双 Y 轴。
